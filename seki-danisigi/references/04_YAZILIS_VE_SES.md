# Yazılış, transkripsiya və səs

## İki yazı qatı

Mənbənin elmi transkripsiyası ilə gündəlik oxunaqlı yazılış fərqlidir.
Bu paket rəsmi “Şəki əlifbası” təyin etmir. Oxunaqlı formalar Azərbaycan
latın qrafikasına yaxın təqdimatdır; bütün fonetik incəlikləri saxlamır.

| Mənbə işarəsi | Bu paketdə oxunaqlı qarşılıq | Qeyd |
|---|---|---|
| š | ş | Transkripsiya uyğunlaşdırması |
| č | ç | Transkripsiya uyğunlaşdırması |
| ǰ | c | Azərbaycan əlifbasındakı c |
| ä | ə | İki yazı sistemini qarışdırmamaq üçün |
| ï | ı | Oxunaqlı təqdimat |
| χ | x | Təxmini qrafik qarşılıq |
| ɣ | ğ | Təxmini qrafik qarşılıq |
| ġ | q | Mənbənin işarəsini oxunaqlı qatla eyniləşdirir |
| ː | : | Səs uzunluğu |

Bu cədvəl tam IPA xəritəsi deyil. Mənbədə əlavə işarələr və diakritiklər var.
`source_form` daxilində olan orijinal işarələri silib sonra “orijinal
transkripsiya” adlandırmaq olmaz. Bazada qarışıq diakritikli saitlər görünə bilər.

## Vurğu, ritm və intonasiya

Uzun sait, vurğulu heca və yüksək səs tonu üç müxtəlif hadisədir.
Yazıdakı `:` səsin yüksək tonla deyildiyini bildirmir.
Fonetik ritmi gülməli yazı üslubu ilə eyniləşdirməyin.

Bu versiyada mətn təhlili aparılıb; audioya əsaslanan intonasiya ölçülməyib.
Ton konturu, tempi və fasilələri göstərən yeni qrafiklər yaradılmayıb.
AI mətni ilə səs yaratmaq ayrıca məsələdir: adi TTS sistemi dialekt səslərini
və uzunluğunu doğru səsləndirməyə bilər. Bu paket belə uyğunluğu təsdiqləmir.

## Özünüz dinləyərkən

1. Məqalə cümləsinin nömrəsini tapın.
2. Standart mənanı oxuyun; sonra səslənməni izləyin.
3. Mətnin işarələdiyi uzunluğu vurğu ilə qarışdırmayın.
4. Eşitdiyiniz yeni variantı tarix və cümlə nömrəsi ilə qeyd edin.
5. Bir danışanın forması üçün bütün bölgəni təmsil edən hökm yazmayın.

Səs mənbəsinin yenidən yayımlanması və model təlimində istifadəsi üçün
müvafiq istifadə hüquqları ayrıca qiymətləndirilməlidir.
